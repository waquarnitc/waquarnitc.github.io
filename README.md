# Inclusive Speech Intelligence — Research Roadmap

A static, responsive GitHub Pages website presenting research themes and proposed research problems around dysarthric speaker verification, children's speech recognition, data augmentation, acoustic features, and speech foundation models.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `speech-research-roadmap`).
2. Upload `index.html` and `README.md` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After GitHub builds the site, the Pages URL will be shown in that section.

## Before publishing
- Confirm the intended researcher and whether the page should be personal, lab-branded, or neutral.
- Review every research idea against the closest recent literature; these are promising hypotheses, not novelty guarantees.
- Add verified contact details and any lab/project links you want to publish.
- Confirm dataset terms, ethics approvals, and privacy requirements before running experiments.
